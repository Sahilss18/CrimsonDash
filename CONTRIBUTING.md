# Contributing Guidelines
 
:clap: :tada: First off, Thanks for taking to time to contribute. :clap: :tada:

Any contributions are welcome.

The below is just some simple ways to contribute, but you can always contribute as your own way.

## Table of Contents

- [Making Pull Requests](#making-pull-requests)
- [Reporting Bugs](#reporting-bugs)
- [You can Contribute as Your Own](#you-can-contribute-as-your-own)

## Making Pull Requests

You can add new features and extra functionality by making pull requests and submitting new features to us using the [Pull Requests](https://github.com/Sahilss18/CrimsonDash/pulls)

## Reporting Bugs

You can report bugs, suggestions, ideas and improvements using the [Issue Tracker](https://github.com/Sahilss18/CrimsonDash/issues).

## You can Contribute as Your Own

All contributions and suggestions are welcome, there is no rule. Everyone is free to contribute.
